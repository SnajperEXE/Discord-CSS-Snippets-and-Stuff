# Discord CSS Snippets and Stuff

A collection of custom CSS snippets, UI tweaks, experiments, and visual enhancements for Discord.

Created mainly for:
- Vencord
- BetterDiscord
- Custom Discord CSS setups

This repository contains reusable snippets that can work independently or be combined into larger custom themes.

# Current Snippets

## Stealth Member List
Collapses the member list into a thin sidebar and expands it on hover.

Features:
- Smooth width transition
- Hidden member content until hover
- Minimal and theme-friendly design
- Works with most Discord themes
